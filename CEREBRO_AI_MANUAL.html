    CEREBRO AI MANUAL

    1. CEREBRO AI¶

    1.1 CEREBRO AI란¶

    CEREBRO AI는 다양한 유형의 데이터를 수집·분석하고, 인공지능 기반 분석 기능을 통해 데이터 간 연관관계와 이상 패턴을 탐지할 수 있는 빅데이터 분석 플랫폼입니다.

    1.2 주요 기능¶

    01. 데이터 탐색 및 전처리¶

    • 다양한 데이터 소스로부터 데이터 수집
    • 분석 목적에 맞는 데이터 정제 및 가공
    • 결측치 처리 및 데이터 전처리 기능 제공
    • 분석 가능한 형태의 데이터 구조 변환 지원

    02. OLAP 분석¶

    • 다차원 데이터 기반 분석 수행
    • 다양한 기준의 데이터 비교 및 탐색
    • 통계 기반 데이터 패턴 분석
    • 시각화를 통한 인사이트 도출

    03. 연관관계 분석¶

    • 데이터 간 연결 관계 시각화
    • 객체 간 관계 및 패턴 분석
    • 이상 패턴 및 연관 구조 탐지
    • 네트워크 기반 관계 분석 지원

    04. 인공지능 모델링¶

    • 머신러닝 및 딥러닝 기반 모델 생성
    • 학습 데이터 기반 예측 분석 수행
    • AI 모델 학습 및 결과 예측 지원
    • 분석 자동화 기반 모델 운영 가능

    1.3 특장점¶

    01. GPT 기반 대화형 분석 환경¶

    세레브로 GPT를 활용한 자연어 기반 분석 기능 제공

    • 자연어 질의응답 기반 데이터 분석
    • 분석 결과 요약 및 인사이트 제공
    • 대화형 흐름 기반 사용자 인터페이스 지원

    02. 원스톱 데이터 분석 환경¶

    데이터 처리부터 분석까지 통합 환경 제공

    • 데이터 전처리 및 통계 분석 통합 지원
    • 직관적인 사용자 중심 인터페이스 구성
    • 별도 개발 없이 분석 업무 수행 가능

    03. 인공지능 개발 자동화¶

    AI 모델 개발 과정을 자동화하여 분석 효율 향상

    • AI 모델 생성 및 학습 자동화
    • 예측 기반 분석 프로세스 지원
    • 반복 분석 업무 간소화

    04. 유연한 확장 구조¶

    사용 환경에 맞는 기능 확장 및 커스터마이징 지원

    • 요구사항 기반 기능 확장 가능
    • 모듈형 구조 기반 기능 구성
    • 사용자 환경 맞춤형 시스템 적용 지원

      • 로그인 후 홈 화면이 열리며, 상단 메뉴에서 데이터마트 를 클릭하여 분석할 자료에 접근합니다.

      • 버튼을 클릭한 후 데이터셋을 업로드합니다.
      • 목록에서 데이터셋 제목을 클릭하여 해당 자료의 분석 화면(데이터 구조)으로 이동합니다.

    • 데이터마트 오른쪽 위의 버튼을 클릭한 후, 데이터에 맞는 등록 방식을 선택합니다.

    3.1.1.1 파일 업로드¶
    • CSV·Excel 파일을 업로드하여 분석에 사용할 물리 데이터셋을 생성하는 기능입니다.
    1. 버튼을 클릭하고 파일 업로드 를 선택합니다.
    2. 데이터셋 제목을 입력하고 CSV 또는 Excel 파일을 업로드합니다.
    3. 등록이 완료되면 목록에서 데이터셋 제목을 클릭하여 분석 화면의 데이터 구조로 이동합니다.

    3.1.1.2 SQL 쿼리¶
    • 등록된 데이터셋을 SQL로 조회하여 필요한 조건과 컬럼으로 구성한 새 데이터셋을 생성하는 기능입니다.
    1. 버튼을 클릭하고 SQL 쿼리를 선택합니다.
    2. 소스의 변경 버튼을 클릭하여 조회할 데이터셋을 선택하고 적용 합니다.
    3. SQL 편집기에 쿼리를 입력합니다. - 대화창에 원하는 내용을 입력하면 AI로 쿼리 초안을 작성할 수도 있습니다.
    4. 실행 버튼을 클릭하여 결과를 미리 확인합니다.
    5. 버튼을 클릭한 후 제목을 입력하고 만들기 를 클릭합니다.
    6. 등록이 완료되면 데이터마트의 SQL 목록에서 생성한 데이터셋을 확인합니다.

    3.1.1.3 데이터셋 조인¶
    • 두 개 이상의 데이터셋을 공통 키 컬럼으로 연결하여 하나의 데이터셋으로 생성하는 기능입니다.
    1. 조인할 CSV·Excel 파일을 파일 업로드로 각각 등록합니다.
    2. 버튼을 클릭하고 데이터셋 조인을 선택합니다.
    3. 사용할 데이터셋을 클릭하여 조인 화면에 추가합니다. 필요하면 대화 접기 버튼을 클릭하여 작업 영역을 넓힙니다.
    4. 한 데이터셋의 키 컬럼을 다른 데이터셋의 같은 키 컬럼으로 끌어 연결하고, 조인 방식과 출력할 컬럼을 확인합니다.
    5. 실행 버튼으로 결과를 미리 확인한 후 버튼을 클릭합니다.
    6. 제목을 입력하고 만들기 를 클릭한 후 데이터마트의 조인 목록에서 생성한 데이터셋을 확인합니다.

      • 미리보기는 최대 50행이 표시되며, 등록이 완료된 데이터셋의 전체 행 수는 목록에서 확인합니다.

    3.1.1.4 DB 추출¶
    • 그룹에 등록된 외부 DB에서 테이블이나 SQL 조회 결과를 추출하여 물리 데이터셋을 생성하는 기능입니다.
    1. 버튼을 클릭하고 DB 추출을 선택합니다.
    2. 위쪽의 DB 연결 목록에서 사용할 연결을 선택합니다.
    3. 스키마 탐색기의 테이블 필터에 테이블명을 입력하고 사용할 테이블을 선택합니다.
    4. 속성 탭에서 컬럼 정보를, 데이터 탭에서 실제 내용을 미리 확인합니다. 필요하면 AI 대화를 접어 작업 영역을 넓힙니다.
    5. SQL 편집기 탭에서 추출할 컬럼과 조건을 지정하고 실행 하여 결과를 확인한 후 버튼을 클릭합니다.
    6. 제목을 입력하고 만들기 를 클릭한 후 데이터마트의 물리 목록에서 생성한 데이터셋을 확인합니다.

    • DB 연결은 그룹에 미리 등록되어 있어야 합니다. 현재 지원되는 DB 유형은 Oracle·MySQL입니다.

    • 컬럼의 데이터를 오름차순 또는 내림차순으로 정렬합니다.

      • Shift 키를 누른 채 다른 컬럼의 정렬 버튼을 클릭하면 여러 컬럼 기준으로 정렬합니다.

    • 조회한 데이터를 csv, xlsx 파일로 변환하여 다운로드합니다.

      • 비교, 분포, 추이, 관계, 공간, 구성, 흐름의 7개 분류에서 차트 를 선택할 수 있습니다.
      • 정렬 목록에서 기본, 이름 오름차순/내림차순, 값 오름차순/내림차순을 선택할 수 있습니다.
      • 차트 화면의 위젯 등록 버튼을 클릭하면 스튜디오에서 사용할 위젯으로 저장됩니다.

    관계 여러 수치 항목이 서로 어떤 관련이 있는지 확인할 때 사용합니다. 히트맵
    공간 위치나 지역을 기준으로 데이터의 차이와 분포를 확인할 때 사용합니다. 지도, 한국 지도, 세계 지도
    구성 전체에서 각 항목이 차지하는 비중을 파악할 때 사용합니다. 파이, 스택막대, 트리맵
    흐름 단계 간 이동이나 항목별 규모의 변화를 살펴볼 때 사용합니다. 샌키, 스트림그래프
    3.2.3.1 비교¶

    항목이나 집단 간 수치의 크기와 차이를 비교할 때 사용합니다. 비교할 지표의 수와 항목의 특성에 따라 차트를 선택합니다.

    • 막대: 지역별 보험금 합계처럼 항목별 수치의 크기나 순위를 비교할 때 사용합니다.
    • 선: 연령대처럼 순서가 있는 항목에 따른 값의 변화를 살펴보거나, 여러 집단의 변화 양상을 비교할 때 사용합니다.
    • 막대+꺾은선: 월별 지급 건수와 평균 보험금처럼 단위나 규모가 다른 두 지표를 한 화면에서 함께 비교할 때 사용합니다.
    • 레이더: 여러 평가 지표를 기준으로 대상별 강점과 약점, 전반적인 특징을 비교할 때 사용합니다.
    3.2.3.1.1 막대¶

    • 막대의 길이로 항목별 수치의 크기와 순위를 비교할 수 있습니다.
      • 그래프 선택에서 비교 - '막대' 항목을 선택합니다.
      • 왼쪽 검색창에서 그래프를 그릴 때 사용할 항목을 검색합니다.
      • 막대그래프에 사용할 분류항목, 비교항목을 지정 후 드래그합니다.
      • 막대그래프에 사용할 측정값을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.
      • 정렬 목록에서 값 내림차순을 선택한 후 다시 '차트 생성' 을 클릭하여 정렬합니다.

    3.2.3.1.2 선¶

    • 항목별 값을 선으로 연결하여 여러 집단의 변화 양상과 차이를 비교할 수 있습니다.
      • 그래프 선택에서 비교 - '선' 항목을 선택합니다.
      • 선그래프에 사용할 분류항목, 비교항목을 지정 후 드래그합니다.
      • 선그래프에 사용할 측정값을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.1.3 막대+꺾은선¶

    • 두 지표를 막대와 꺾은선으로 함께 표시하여 값의 차이와 변화 양상을 확인할 수 있습니다.
      • 그래프 선택에서 비교 - '막대+꺾은선' 항목을 선택합니다.
      • 분류항목을 지정 후 드래그합니다.
      • 막대 측정값과 꺾은선 측정값을 각각 지정 후 드래그합니다.
        • 꺾은선 측정값은 오른쪽 Y축으로 표시됩니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.1.4 레이더¶

    • 여러 지표를 방사형 축에 표시하여 대상별 특징과 지표 간 차이를 한눈에 비교할 수 있습니다.
      • 그래프 선택에서 비교 - '레이더' 항목을 선택합니다.
      • 레이더에 사용할 지표 항목을 지정 후 드래그합니다.
        • 지표항목은 숫자만 사용가능합니다.
      • 레이더에 사용할 비교항목을 지정 후 드래그합니다.
      • 왼쪽 항목 목록에서 비교항목을 펼쳐 비교할 값만 선택할 수 있습니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.2 분포¶

    데이터가 어느 값이나 구간에 집중되어 있는지, 얼마나 넓게 퍼져 있는지 확인할 때 사용합니다. 집단별 분포의 차이나 다른 값들과 동떨어진 데이터도 살펴볼 수 있습니다.

    • 히스토그램: 보험금을 금액 구간별로 나누어 지급 건수가 많이 모인 금액대를 확인할 때 사용합니다.
    • 박스플롯: 보험종류별 보험금의 중앙값과 퍼진 정도, 이상치를 비교할 때 사용합니다.
    • 산점도: 보험료와 보험금처럼 두 수치 항목의 관계를 살펴보고, 값이 모인 집단이나 동떨어진 점을 확인할 때 사용합니다.
    • 파이: 보험종류별 지급 건수처럼 범주별 빈도가 전체에서 차지하는 비중을 파악할 때 사용합니다.
    3.2.3.2.1 히스토그램¶

    • 수치 데이터를 구간별로 나누어 데이터가 많이 모인 구간과 전체적인 분포를 확인할 수 있습니다.
      • 그래프 선택에서 분포 - '히스토그램' 항목을 선택합니다.
      • 히스토그램에 사용할 분포항목을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.2.2 박스플롯¶

    • 상자와 수염으로 집단별 중앙값과 데이터가 퍼진 정도, 이상치를 확인할 수 있습니다.
      • 그래프 선택에서 분포 - '박스플롯' 항목을 선택합니다.
      • 박스플롯에 사용할 측정값, 그룹기준 항목을 지정 후 드래그합니다.
        • 측정값은 숫자만 사용가능합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.2.3 산점도¶

    • 두 수치 항목의 값을 점으로 표시하여 항목 간 관계와 데이터가 모이거나 흩어진 모습을 확인할 수 있습니다.
      • 그래프 선택에서 분포 - '산점도' 항목을 선택합니다.
      • 산점도에 사용할 가로축, 세로축, 크기기준, 그룹기준 항목을 지정 후 드래그합니다.
        • 가로축, 세로축, 크기기준은 숫자만 사용가능합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.2.4 파이¶

    • 범주별 빈도를 원의 조각으로 나누어 각 범주가 전체에서 차지하는 비중을 확인할 수 있습니다.
      • 그래프 선택에서 분포 - '파이' 항목을 선택합니다.
      • 파이그래프에 사용할 분류항목, 측정값을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.
      • 정렬을 통해 값 내림차순으로 다시 정렬합니다.

    3.2.3.3 추이¶

    시간이나 순서에 따른 값의 증가·감소와 변화 패턴을 살펴볼 때 사용합니다. 월별 지급 건수나 연도별 보험금처럼 기간에 따른 변화를 확인하는 데 적합합니다.

    • 막대: 월별 지급 건수처럼 기간별 수치의 차이를 구분하여 비교할 때 사용합니다.
    • 선: 월별 평균 보험금처럼 연속된 기간의 변화 방향과 추세를 살펴볼 때 사용합니다.
    • 영역: 시간에 따른 값의 변화를 살펴보면서 수치의 규모를 채워진 영역으로 강조할 때 사용합니다.
    3.2.3.3.1 영역¶

    • 시간에 따른 값의 변화를 채워진 영역으로 표시하여 변화 추세와 규모를 함께 확인할 수 있습니다.
      • 그래프 선택에서 추이 - '영역' 항목을 선택합니다.
      • 영역그래프에 사용할 분류 항목, 비교항목, 측정값을 지정 후 드래그합니다.
        • 날짜 항목은 연도, 분기, 월, 일 단위로 묶어서 사용할 수 있습니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.4 관계¶

    여러 수치 항목이 서로 얼마나 관련되어 있는지 확인할 때 사용합니다. 함께 증가하거나 감소하는 항목을 찾아 분석할 대상을 좁힐 수 있습니다.

    • 히트맵: 여러 수치 컬럼의 상관관계를 색의 차이로 표현하여 서로 관련성이 강한 항목을 빠르게 찾을 때 사용합니다.
    3.2.3.4.1 히트맵¶

    • 수치 항목 간 상관관계를 색으로 표현하여 관계의 방향과 강도를 한눈에 확인할 수 있습니다.
      • 그래프 선택에서 관계 - '히트맵' 항목을 선택합니다.
      • 비교항목을 확인합니다. (숫자 항목이 자동으로 지정됩니다.)
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.5 공간¶

    위치나 지역을 기준으로 데이터가 어디에 모여 있고 지역마다 어떤 차이가 있는지 확인할 때 사용합니다.

    • 지도: 위도·경도가 있는 지점의 위치와 수치를 지도에 표시하여 분포를 확인할 때 사용합니다.
    • 한국 지도: 시도·시군구별 보험금 합계처럼 국내 지역별 수치의 차이를 색으로 비교할 때 사용합니다.
    • 세계 지도: 국가별 매출이나 고객 수처럼 국가 단위의 차이와 분포를 비교할 때 사용합니다.
    3.2.3.5.1 지도¶

    • 위도·경도를 기준으로 데이터를 지도에 표시하여 지점별 위치와 수치의 분포를 확인할 수 있습니다.
      ※ 지도를 사용하기 위해선 데이터에 위/경도 정보가 있어야 합니다.
      • 그래프 선택에서 공간 - '지도' 항목을 선택합니다.
      • 지도에 사용할 경도, 위도, 위치명, 측정값 항목을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 지도를 생성합니다.

    3.2.3.5.2 한국 지도¶

    • 시도·시군구별 수치를 색으로 구분하여 국내 지역 간 차이와 분포를 확인할 수 있습니다.
      • 그래프 선택에서 공간 - '한국 지도' 항목을 선택합니다.
      • 지역(시도), 측정값 항목을 지정 후 드래그합니다.
        • 지역(시군구)를 함께 지정하면 시도를 클릭하여 시군구 단위로 볼 수 있습니다.
      • '차트 생성' 을 클릭하여 지도를 생성합니다.

    3.2.3.6 구성¶

    전체에서 각 항목이 차지하는 비중을 파악하거나, 집단별로 구성의 차이를 비교할 때 사용합니다.

    • 파이: 전체 보험금 중 보험종류별 금액처럼 하나의 전체를 이루는 항목들의 비중을 확인할 때 사용합니다.
    • 스택막대: 막대 안에 세부 항목을 쌓아 항목별 전체 규모와 구성을 함께 비교할 때 사용합니다.
    • 트리맵: 항목이 많을 때 사각형의 크기로 각 항목의 비중을 표현하여 큰 비중을 차지하는 항목을 찾을 때 사용합니다.
    3.2.3.6.1 파이¶

    • 항목별 수치를 원의 조각으로 나누어 전체에서 각 항목이 차지하는 비율을 확인할 수 있습니다.
      • 그래프 선택에서 구성 - '파이' 항목을 선택합니다.
      • 파이 그래프에서 비율을 확인할 측정값 항목을 지정 후 드래그합니다.
      • 파이 그래프에서 비교할 항목을 지정 후 드래그 합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.
      • 정렬을 통해 값 오름차순으로 다시 정렬합니다.

    3.2.3.6.2 스택막대¶

    • 세부 항목을 막대 안에 쌓아 표시하여 항목별 전체 규모와 구성을 함께 비교할 수 있습니다.
      • 그래프 선택에서 구성 - '스택막대' 항목을 선택합니다.
      • 스택막대에 사용할 분류 항목을 지정 후 드래그합니다.
      • 스택막대에 사용할 측정값을 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.6.3 트리맵¶

    • 항목별 비중을 사각형의 크기로 표현하여 전체 구성과 비중이 큰 항목을 한눈에 확인할 수 있습니다.
      • 그래프 선택에서 구성 - '트리맵' 항목을 선택합니다.
      • 트리맵에 사용할 비교 항목을 지정 후 드래그합니다.
      • 트리맵에 사용할 측정값을 지정 후 드래그합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.7 흐름¶

    단계나 집단 사이의 이동을 살펴보거나, 시간에 따라 여러 항목의 규모와 구성이 어떻게 달라지는지 확인할 때 사용합니다.

    • 샌키: 고객 유입 경로에서 구매 단계로 이어지는 흐름처럼 단계 사이의 연결과 이동량을 확인할 때 사용합니다.
    • 스트림그래프: 월별 상품군 매출처럼 시간에 따라 여러 항목의 규모와 구성이 함께 변하는 모습을 살펴볼 때 사용합니다.
    3.2.3.7.1 샌키¶

    • 단계 사이의 연결을 띠로 표시하여 데이터의 이동 경로와 이동량을 확인할 수 있습니다.
      • 그래프 선택에서 흐름 - '샌키' 항목을 선택합니다.
      • 샌키에 사용할 출발기준, 도착기준을 지정 후 드래그합니다.
      • 샌키에 사용할 측정값을 지정 후 드래그 합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.3.7.2 스트림그래프¶

    • 항목별 수치를 흐르는 띠 모양으로 표시하여 시간에 따른 규모와 구성의 변화를 확인할 수 있습니다.
      • 그래프 선택에서 흐름 - '스트림그래프' 항목을 선택합니다.
      • 스트림그래프에 사용할 가로축, 흐름기준, 측정값을 지정 후 드래그합니다.
        • 가로축은 숫자 또는 날짜 항목만 사용가능합니다.
      • '차트 생성' 을 클릭하여 그래프를 생성합니다.

    3.2.4 편집 이력¶

    • 데이터에 대한 작업 이력을 조회하는 기능입니다.
      • 전처리 실행, 규칙 저장, 모델 학습·저장, 위젯 저장·삭제 등의 작업이 시각, 사용자, 행위, 요약과 함께 표시됩니다.
      • 더 보기 버튼을 클릭하여 이전 이력을 확인합니다.

    3.3 전처리¶

    • 업로드한 데이터에서 컬럼을 추가하거나 결측치를 제거하는 등의 전처리 활동을 수행하는 기능입니다.
      • 전처리 설정 : 선택한 데이터에 전처리를 적용한 뒤 전처리를 적용한 뒤 확인합니다.
      • 데이터 구조 : 전처리 된 자료에 대한 데이터 정보를 조회합니다.
      • 데이터 보기 : 전처리 된 자료에 대한 실제 데이터를 조회합니다.
      • 차트 시각화 : 전처리 된 자료 데이터를 차트를 통해 시각화합니다.

    3.3.1 전처리 설정¶

    • 데이터 전처리는 데이터의 품질을 개선하는 과정으로, 특히 머신러닝 학습 전 데이터의 오류와 불일치를 점검하여 모델의 성능과 예측 결과의 신뢰성을 높이기 위한 필수적인 과정입니다.
      • 데이터 내 컬럼을 합치거나 가공하여 신규 생성 및 기존 컬럼을 삭제 할 수 있습니다.
      • 데이터 내 결측값, 중복값이 있을 경우 대체하여 가공할 수 있습니다.
      • 이상치를 처리하고 정규화 기능을 통해 데이터 스케일링을 지원합니다.
      • 왼쪽 단계 목록에 추가한 전처리가 순서대로 표시되며, 버튼을 클릭하면 모든 단계가 실행되어 결과가 저장됩니다.
      • 오른쪽 현재 단계 데이터 미리보기에서 단계별 결과 건수를 확인합니다.

    3.3.1.1 AI¶

    AI가 데이터를 분석하여 전처리 항목을 추천하거나, 사용자가 입력한 요청에 따라 전처리 항목을 생성하는 기능입니다.

    3.3.1.1.1 AI전처리¶
    • GPT가 사용자 데이터를 분석하여 자동으로 전처리할 항목을 생성합니다.
      • 상단에서 AI 전처리 버튼을 클릭합니다.
      • GPT가 내부 데이터를 분석한 결과와 전처리 대상항목을 확인합니다.
      • 왼쪽 단계 목록에 '새로 추가' 로 표시된 항목을 클릭하여 내용을 확인합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.1.2 AI 직접입력¶
    • 사용자가 GPT에게 전처리 요구내역을 입력하여 자동으로 전처리 항목을 생성합니다.
      • 상단에서 직접 입력 버튼을 클릭합니다.
      • 옆에 표시되는 입력창에 전처리 요청사항을 입력 후 송신 버튼을 클릭합니다.
      • 요청사항에 따라 GPT가 분석한 결과 및 전처리 대상항목을 확인합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    ※ 기존 시연의 결과 설정을 기준으로 재구성한 설명용 예시입니다. 기존 전처리 내역 없이 지급연도 항목생성 한 단계만 표시합니다.

    3.3.1.2 데이터 정제¶

    분석에 필요한 데이터만 선택하고, 컬럼의 값이나 데이터 형식을 변경하여 데이터를 정리하는 기능입니다.

    3.3.1.2.1 필터링¶

      • 필터링할 컬럼, 조건, 값을 지정합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.2.2 값 변경¶
    • 컬럼 내 특정 값을 다른 값으로 바꿉니다.
      • 상단에서 값변경 버튼을 클릭합니다.
      • 값을 변경할 컬럼을 선택하고 대상값과 치환값을 입력합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.2.3 형 변환¶
    • 컬럼의 데이터 형식을 변경합니다.
      • 상단에서 형변환 버튼을 클릭합니다.
      • 형변환할 컬럼과 처리방법(정수형, 부동소수점, 문자열, 날짜 및 시간, 참/거짓, 범주)을 선택합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.3 결측/중복¶

    중복된 데이터를 제거하고, 결측값을 제거하거나 다른 값으로 대체하여 데이터의 품질을 높이는 기능입니다.

    3.3.1.3.1 중복값¶
    • 컬럼 내 중복 된 데이터 값을 제거합니다.

      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.3.2 결측값¶

      • 모든 결측 항목 추가를 클릭하거나 결측값을 처리할 컬럼을 선택하고 처리방법을 선택합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    3.3.1.5 스케일링¶

    수치 데이터의 분포와 범위를 조정하고 이상치를 처리하여 분석에 적합한 형태로 변환하는 기능입니다.

    3.3.1.5.1 정규화¶
    • 데이터 내 분포나 범위를 초과한 값을 정규화합니다.
      • 상단에서 정규화 버튼을 클릭합니다.
      • 정규화할 컬럼 및 처리방법(StandardScaler, MinMaxScaler, MaxAbsScaler, RobustScaler)을 선택합니다.
      • 버튼을 클릭하여 결과를 확인합니다.
    처리방법 간단한 설명
    StandardScaler 각 값에서 평균을 빼고 표준편차로 나누어, 평균 0과 표준편차 1을 기준으로 데이터의 크기를 조정합니다.
    MinMaxScaler 최솟값과 최댓값을 기준으로 데이터의 범위를 조정합니다. 기본 범위는 0～1입니다.
    MaxAbsScaler 각 값을 해당 컬럼의 가장 큰 절댓값으로 나눕니다. 0과 값의 부호를 유지하면서 데이터의 크기를 조정합니다.
    RobustScaler 중앙값과 사분위 범위(상위 25% 경계값과 하위 25% 경계값의 차이)를 기준으로 크기를 조정하여, 이상치의 영향을 줄입니다.

    3.3.1.5.2 이상치¶
    • 데이터 이상치를 변환합니다.
      • 상단에서 이상치 버튼을 클릭합니다.
      • 전처리할 이상치 컬럼을 선택하고 방법,처리,옵션을 입력합니다.
      • 버튼을 클릭하여 결과를 확인합니다.

    방법 (이상치를 판단하는 기준)

    방법 설명 예시
    IQR (사분위수) 데이터를 작은 값부터 정렬했을 때 하위 25% 지점의 값(Q1)과 75% 지점의 값(Q3)을 기준으로 판단합니다. 두 값의 차이인 사분위 범위(IQR = Q3 − Q1)는 데이터 가운데 50%가 퍼져 있는 범위입니다. Q1 − Factor × IQR보다 작거나 Q3 + Factor × IQR보다 큰 값을 이상치로 판단합니다. Q1이 100, Q3이 140이면 IQR은 40입니다. Factor를 1.5로 설정하면 하한은 40, 상한은 200이므로, 10과 250은 이상치로 판단합니다.
    Z Score 값이 평균에서 표준편차의 몇 배만큼 떨어져 있는지 나타냅니다. Z Score = (값 − 평균) ÷ 표준편차로 계산하며, 절댓값이 설정한 기준값보다 크면 이상치로 판단합니다. 평균이 100, 표준편차가 20일 때 값 180의 Z Score는 4입니다. 기준값을 3으로 설정하면 허용 범위는 40～160이므로, 180은 이상치로 판단합니다.
    • 표준편차는 값들이 평균 주변에서 얼마나 퍼져 있는지 나타내는 수치입니다. Z Score가 4이면 평균보다 표준편차의 4배만큼 큰 값이라는 뜻입니다.

    처리 (이상치로 판단한 값을 처리하는 방식)

    처리 설명 예시
    Clip (자르기) 하한보다 작은 값은 하한으로, 상한보다 큰 값은 상한으로 변경합니다. 해당 행을 삭제하지 않고 값만 경계값으로 바꿉니다. IQR 예시의 허용 범위가 40～200이면, 10은 40으로, 250은 200으로 변경합니다. 범위 안의 값은 유지합니다.
    Drop (삭제) 이상치가 포함된 행을 삭제합니다. 해당 행의 다른 컬럼 값도 함께 삭제되어 전체 데이터 건수가 줄어듭니다. 선택한 컬럼의 값 250이 이상치라면, 그 값이 있는 행 전체를 삭제합니다.
    Mean (평균대체) 이상치를 해당 컬럼의 평균값으로 바꿉니다. 평균은 값의 합을 개수로 나눈 값입니다. 값 250이 이상치이고 대체에 사용할 평균값이 120이면, 250을 120으로 변경합니다.
    Median (중위수대체) 이상치를 해당 컬럼의 중위수(중앙값)로 바꿉니다. 중위수는 값을 크기순으로 정렬했을 때 가운데 값이며, 개수가 짝수이면 가운데 두 값의 평균입니다. 값 250이 이상치이고 대체에 사용할 중위수가 115이면, 250을 115로 변경합니다.

    옵션 (이상치로 판단할 범위 조정)

    옵션 의미 설정 예시
    IQR의 Factor (배수) 사분위 범위에 곱하는 숫자입니다. 숫자가 작을수록 허용 범위가 좁아져 더 많은 값을 이상치로 판단하고, 클수록 허용 범위가 넓어집니다. Q1이 100, Q3이 140일 때 Factor 1.5의 허용 범위는 40～200입니다. Factor를 3으로 높이면 −20～260으로 넓어져, 값 250은 이상치로 판단하지 않습니다.
    Z Score의 기준값 (임계값) 평균에서 표준편차의 몇 배까지 허용할지 정하는 숫자입니다. IQR의 Factor와 마찬가지로 숫자가 작을수록 더 많은 값을 이상치로 판단합니다. 평균이 100, 표준편차가 20일 때 기준값 3은 평균에서 ±60인 40～160을 허용합니다. 기준값을 2로 낮추면 60～140으로 좁아져, 값 150도 이상치로 판단합니다.
    • 위 숫자는 설정의 의미를 설명하기 위한 예시입니다. 방법과 옵션으로 이상치를 판단한 뒤, 선택한 처리 방식에 따라 값을 변경하거나 해당 행을 삭제합니다.

    적용하기 전 추가한 전처리 항목을 취소합니다.

    • 추가한 항목이 사라지고 마지막으로 적용한 상태로 돌아갑니다.
    • 이미 적용한 단계는 왼쪽 단계 목록의 휴지통 버튼으로 삭제한 뒤 적용합니다.

    • 원본의 데이터 보기(3.2.2)와 기능 및 사용 방법이 동일합니다. 전처리가 적용된 데이터를 표로 조회하고, 필터링과 그룹화를 통해 처리 결과를 살펴봅니다.

    • 상세 사용법은 3.2.2 데이터 보기를 참조하세요.

    3.4 통계 분석¶

    • BI(OLAP) : 분석 기준과 집계 항목을 선택하여 데이터를 피벗 테이블로 요약하고, 다양한 관점에서 비교·분석하는 기능입니다.
    • 연관관계분석 : 데이터 항목 간 연결 관계를 네트워크로 시각화하여, 서로 연관된 항목과 주요 패턴을 탐색하는 기능입니다.

    3.4.1 BI(OLAP)¶

    • 분석 데이터를 피벗화 하여 데이터를 분석하는 기능입니다.
      • 분석 데이터를 다차원으로 분석하고 이를 차트, 원본 자료, 피벗자료와 비교할 수 있습니다.
      • Column(열), Row(행), Measure(측정값)에 항목을 드래그한 후 분석 실행 을 클릭합니다.
      • 정렬(이름 또는 측정값 기준)과 상위 N을 지정하여 원하는 행만 표시할 수 있습니다.
      • 결과 화면의 엑셀 다운로드 버튼으로 결과를 내려받고, 위젯 등록 버튼으로 스튜디오·보고서에서 사용할 위젯을 저장합니다.

    3.4.1.1 피벗그래프¶
    • 피벗 그래프를 통해 데이터간 비율 및 건수를 파악할 수 있습니다.
      • 표시 숫자단위 간략화 를 클릭하여 천단위 이상의 숫자건을 간략하게 확인할 수 있습니다.
      • 피벗셀을 클릭하여 해당 조건에 맞는 상세건을 확인할 수 있습니다.

    3.4.1.2 선그래프¶
    • 선 그래프를 통해 데이터간 관계를 선으로 확인할 수 있습니다.
      • 축 분리 를 클릭하여 피벗 항목간의 차를 비교 할 수 있습니다.
      • 축 반전 을 클릭하여 X,Y축을 반전시켜 그릴 수 있습니다.
      • 위젯 등록 을 눌러 그래프를 저장할 수 있습니다.

    3.4.1.3 막대그래프¶
    • 막대 그래프를 통해 데이터간 관계를 막대로 확인할 수 있습니다.
      • 축 분리 를 클릭하여 피벗 항목간의 차를 비교 할 수 있습니다.
      • 축 반전 을 클릭하여 X,Y축을 반전시켜 그릴 수 있습니다.
      • 적층형 그래프 를 클릭하여 값에 대하여 적층형으로 확인 할 수 있습니다.
      • 위젯 등록 을 눌러 그래프를 저장할 수 있습니다.

    3.4.1.4 표그래프¶
    • 표 그래프를 통해 데이터간 집계 정보를 확인할 수 있습니다.
      • 표시 숫자단위 간략화 를 클릭하여 천단위 이상의 숫자건을 간략하게 확인할 수 있습니다.
      • 위젯 등록 을 눌러 그래프를 저장할 수 있습니다.

    3.4.1.5 필터그래프¶
    • 필터그래프를 통하여 원본자료에 대한 정보를 확인할 수 있습니다.
      • 표시 숫자단위 간략화 를 클릭하여 천단위 이상의 숫자건을 간략하게 확인할 수 있습니다.
      • 위젯 등록 을 눌러 그래프를 저장할 수 있습니다.

    💡 참고 : BI 분석 실행 및 결과 활용

    자동 분석 실행

    • 분석 조건을 바꿀 때마다 결과를 자동으로 갱신하여 여러 조건을 비교할 때 편리합니다.
      • 분석 실행 왼쪽의 버튼으로 자동 실행을 켜거나 끕니다. 활성화한 상태에서 열·행·측정값 등 분석 조건을 변경하면 결과에 반영됩니다.

    엑셀 다운로드

    • 현재 분석 결과를 엑셀 파일로 저장하여 집계 값을 확인하거나 다른 문서 작성에 활용합니다.
      • 분석을 실행한 뒤 결과 영역 위쪽의 버튼을 클릭합니다.

    위젯 등록

    • 분석 결과를 위젯으로 저장하여 스튜디오나 보고서에서 다시 활용합니다.
      • 결과 영역 위쪽의 버튼을 클릭합니다. 확인 창에서 알아보기 쉬운 이름을 입력한 뒤 버튼을 클릭하여 저장합니다.

    저장된 위젯

    • 이전에 등록한 BI 위젯을 확인하고 다시 불러올 때 사용합니다.
      • BI 화면 오른쪽 위의 버튼을 클릭하고 사용할 위젯을 선택합니다.
      • 등록한 위젯은 스튜디오의 저장된 위젯 목록에서도 확인할 수 있습니다. 대시보드에 활용하는 방법은 5.3.8 저장된 위젯 가져오기를 참조합니다.

    스튜디오의 저장된 위젯 목록 예시입니다. 위젯 이름과 원본 데이터, 사용처 등을 확인할 수 있습니다.

    3.4.2 연관관계분석¶

    • 전처리 된 데이터 항목 간 연관관계를 분석도로 확인하는 기능입니다.
      • 항목간 필터링 , 관계, 패턴 및 빈도 분석을 통해 컬럼 간 관계를 분석할 수 있습니다.
      • 분석도 오른쪽 아래에 표시 중인 노드(node), 연결선(edge), 행(row) 수가 표시됩니다.
      • 왼쪽 메뉴의 연관관계분석 옆 버튼을 클릭하면 분석도를 새 창으로 열 수 있습니다. ※ 노드 수가 최대 노드 수를 넘으면 분석도가 표시되지 않으므로, 분석 항목 선택에서 항목 수를 줄여 사용합니다.

    3.4.2.1 분석 항목 선택¶
    • 연관관계 분석에 사용할 항목을 선택합니다.
      • 오른쪽 상단에 분석 항목 선택 버튼을 클릭합니다.
      • 항목별 형식과 노드 수를 확인하고 분석에 사용할 항목을 선택한 후 확인 버튼을 클릭합니다.
      • 선택한 항목을 기준으로 연관관계 분석도가 표기됩니다.

    💡 참고 : 분석 대상 선택

    • 연관관계 분석도에 표기할 대상 항목을 선택합니다.
      • 좌측 분석 항목 목록에서 항목명을 클릭합니다.
      • 클릭한 항목의 노드를 숨기거나 다시 표시하여 항목 간 연관관계를 분포도로 표시합니다.

    3.4.2.2 필터¶
    • 특정 검색값과 일치하는 노드만 표시합니다.
      • 우측 상단 필터 버튼을 클릭합니다.
      • 항목별로 필터링할 값을 선택 후 적용 버튼을 클릭합니다.
      • 선택한 항목별로 노드가 필터링 되어 분포도에 표기됩니다.

    3.4.2.3 검색 필터¶
    • 항목별 검색 조건에 맞는 노드를 표시합니다.
      • 오른쪽 도구에서 검색필터 버튼을 클릭합니다.
      • 등록하기 를 클릭하고 필터링할 항목을 선택 한 후 버튼을 클릭합니다.
      • 검색할 조건(일치, 다중일치, 포함, 제외, 시작일치, 끝일치)을 선택하고 상세 조건을 입력한 후 버튼을 클릭합니다.

    3.4.2.4 분석도 레이아웃 변경¶
    • 분석도의 레이아웃을 변경합니다.
      • 오른쪽 도구에서 레이아웃 버튼을 클릭합니다.
      • 클릭할 때마다 분포도의 배치 형태가 변경됩니다. (수평형, 수직형, 군집형)

    3.4.2.5 설정¶
    • 분석도에 관하여 노드 간 UI를 설정합니다.
      • 오른쪽 도구에서 설정 버튼을 클릭합니다.
      • 노드 간격을 드래그 하여 수정합니다.
      • 글씨 크기를 드래그 하여 수정합니다.
      • 이름 표시 옆 스위치 를 클릭하여 이름을 숨기거나 보이도록 합니다.
      • 엣지 표시 옆 스위치 를 클릭하여 노드 간 선(엣지)을 숨기거나 보이도록 합니다.
      • 엣지설정에서 를 클릭하여 노드 간 연결된 빈도수 별로 색상을 다르게 표기합니다.
        버튼 클릭시 빈도수 기준이 차례로 추가되며 두께, 투명도를 조절할 수 있습니다.

    3.4.2.6 관계¶
    • 선택한 노드를 기준으로 직접 연결된 다른 노드(1차 관계)와 해당 항목의 값을 확인합니다. 관심 있는 값이 어떤 항목과 연결되어 있는지 살펴보고, 노드 간 관계를 구체적으로 파악할 때 활용합니다.
      • 오른쪽 도구에서 관계 버튼을 클릭합니다.
      • 관계를 확인하고자 하는 노드 중 하나를 클릭합니다.
      • 노드 연관관계 창에서 클릭한 노드와 1차로 연결된 항목과 값을 확인할 수 있습니다.

    💡 참고 : 연계분석

    • 선택한 노드의 값을 다른 데이터셋의 컬럼과 연결하여 관련 데이터를 함께 확인할 수 있습니다.
      • 저장된 위젯 테스트1을 불러온 뒤, 관계 버튼을 클릭하고 보험사기여부의 사기 노드를 선택합니다.
      • 노드 연관관계 창에서 연계분석 버튼을 클릭합니다.
      • 연관관계 설정 창에서 데이터셋을 보험료지급현황, 연결할 컬럼을 보험사기여부로 선택하고 체크 버튼을 클릭합니다.
      • 연계분석 버튼을 다시 클릭하면 연결한 데이터셋에서 사기에 해당하는 데이터가 별도 분석 화면에 표시됩니다.
      • 분할 방향 → 상하를 선택하면 기존 분석 화면은 위쪽에, 연결된 분석 화면은 아래쪽에 표시됩니다.

    3.4.2.7 패턴분석¶
    • 관심 있는 노드를 지정하여 노드 사이에 어떤 경로가 이어져 있는지 확인합니다. 지정한 노드가 연결되는 경로를 분석도에 표시하여, 여러 항목이 어떤 조합으로 연결되는지 살펴볼 수 있습니다.
      • 오른쪽 도구에서 패턴분석 버튼을 클릭합니다.
      • 버튼을 클릭하여 분석할 패턴을 추가합니다.
      • 항목 및 노드를 선택한 후 버튼을 클릭하여 패턴에 노드를 추가합니다.
      • 입력한 노드간 패턴 관계가 분포도에 표기됩니다.

    3.4.2.8 빈도분석¶
    • 각 기준마다 빈도가 많은 경로를 표시합니다.
      • 오른쪽 도구에서 빈도분석 버튼을 클릭합니다.
      • 버튼을 클릭할 때마다 1등, 2등, 3등 빈도 경로가 차례로 추가됩니다.
      • 분포도 내 가장 많은 빈도를 가지고 있는 순서대로 분포도에 색상으로 표기됩니다.
      • 빈도 분석(상위 퍼센트)에서 1%, 5%, 10%, 20% 중 하나를 선택하여 자주 나타나는 연결 경로의 표시 범위를 조절합니다.
        • 1%처럼 작은 비율은 빈도가 높은 경로에 집중할 때, 20%처럼 큰 비율은 더 많은 경로를 함께 살펴볼 때 사용합니다.

    3.4.2.9 초점¶
    • 구성도의 초점을 가운데로 지정합니다.
      • 분석도를 확대하거나 이동한 후 오른쪽 도구에서 초점 버튼을 클릭합니다.
      • 초점이 가운데로 재지정 되어 분포도가 표기됩니다.

    3.4.2.10 위젯저장¶
    • 생성한 구성도를 위젯으로 저장합니다.
      • 우측 상단 위젯 저장 버튼을 클릭합니다.
      • 저장 확인 창에서 예 를 클릭하여 저장합니다.
      • 이후 저장된 위젯 버튼을 클릭하여 저장한 위젯을 확인하고 불러오거나 이름 변경 , 삭제 할 수 있습니다.

    3.4.2.11 미러분석¶
    • 같은 데이터의 분석도를 나란히 띄우고, 각 화면에 서로 다른 필터 조건을 적용하여 노드 간 관계를 비교합니다. 조건에 따라 연결되는 항목과 경로가 어떻게 달라지는지 확인할 때 유용합니다.
      • 오른쪽 도구에서 미러 분석 버튼을 클릭하면 화면이 A, B로 분할됩니다.
      • 화면 동기화에서 A → B, B → A 를 클릭하여 한쪽 화면의 상태를 다른 쪽으로 복사합니다.
      • 통합필터 를 사용하면 분할된 모든 화면에 같은 검색 조건을 적용합니다.
      • 오른쪽 닫기 버튼을 클릭하여 분할된 화면을 닫습니다.

    3.5 기계학습¶

    • 전처리 된 데이터를 기반으로 알고리즘 유형별 인공지능 모델을 학습하는 기능입니다.
      • 알고리즘 유형별로 학습한 후 모델을 생성, 튜닝, 예측 기능을 수행할 수 있습니다.
      • 데이터의 형태와 해결하려는 문제의 목적에 따라 모델을 선택합니다.
      • 모델 종류는 아래와 같이 5가지 모델이 있습니다.
      • 학습 중에는 진행 단계(데이터 다운로드, 모델 학습, 측정 결과 저장)와 진행률이 표시되며, 학습 중단 버튼으로 중단할 수 있습니다.

    시계열 시간에 따른 변화와 반복되는 패턴을 학습하여 미래의 값을 예측합니다. 월별 매출, 일별 방문자 수 예측

    3.5.1 회귀모델¶

    • 회귀 모델은 과거의 데이터를 바탕으로 연속된 '숫자(값)'를 예측하는 모델입니다.

      • "이 정도 스펙의 아파트라면 매매가가 얼마 정도 할까?"를 추론하는 것과 같습니다.
      • 실제 적용 사례 : 매출액 전망, 원자재 가격 예측, 예상 방문자 수 추정

    • 모델 학습

      • 영향요인 선정 : 예측 항목에 영향을 줄 수 있는 데이터를 선택합니다.
        • 샘플데이터 열기 를 클릭합니다.
        • 데이터를 확인하고 학습에 필요한 컬럼을 선정하여 선택합니다.
      • 예측항목 선정 : 예측할 데이터를 선택합니다.
        • 샘플데이터를 확인하여 학습결과로 예측할 항목을 선택합니다.
        • 샘플데이터 닫기 를 클릭합니다.
      • 자동 전처리 설정 : 학습할 데이터 내에 전처리 방식을 선정합니다.
        • 결측값 대치 방식 등 전처리에 필요한 설정을 지정할 수 있습니다.
        • 폴더모양 버튼을 클릭하면 상세한 설정이 가능합니다.
      • 알고리즘 : 결과 표의 실행 스위치로 학습할 알고리즘을 선정합니다.
      • 학습 데이터 비율 선정 : 학습에 사용되는 난수와 비율을 조정합니다.
        • 학습에 필요한 난수를 숫자로 입력합니다. 랜덤생성 버튼을 누르면 임의의 값이 설정됩니다.
        • 학습용, 검증용 건수를 확인하며 학습과 테스트 데이터의 비율을 설정합니다.

    • 모델 튜닝

        • 전체 다운로드 버튼을 누르면 csv파일로 다운로드 합니다.

      • 모델예측 : 사용자가 임의로 변수 내역을 작성하여 데이터 예측 정확도를 파악합니다.

        • 업로드하여 예측 - 파일을 선택하여 대량의 케이스에 대해 예측합니다.

      • 다운로드 : 모델 완성 을 클릭하여 학습·테스트 데이터를 모두 학습한 모델을 완성한 후 모델 다운로드를 할 수 있으며, 적용가능한 python 소스코드를 확인하고 코드 복사 로 복사할 수 있습니다.

    3.5.3 군집모델¶

    • 군집 모델은 아무런 정답(라벨)이 없는 상태에서, 데이터들의 순수한 유사성만을 따져서 비슷한 것끼리 묶어주는 모델입니다.

      • "비슷한 옷을 입은 사람들끼리 알아서 모여보세요"라고 하는 것과 같습니다.
      • 실제 적용 사례 : 고객 세그먼트(타겟층) 분류, 추천 시스템을 위한 유사 아이템 그룹화

    • 모델 학습

      • 변수 선정 : Clustering(군집) 모델 생성 시 항목에 영향을 줄 수 있는 데이터를 선택합니다.

        • 샘플데이터 열기 를 클릭합니다.
        • 데이터를 확인하고 학습에 필요한 컬럼을 선정하여 선택합니다.

      • 자동 전처리 설정 : 학습할 데이터 내에 전처리 방식을 선정합니다.

        • 전처리에 필요한 설정을 지정할 수 있습니다.
        • 폴더모양 버튼을 클릭하면 상세한 설정이 가능합니다.
      • 군집 개수 설정 : 그룹으로 나뉘어질 개수를 지정합니다.
        • 1~50사이의 숫자를 입력하거나 슬라이더를 드래그하여 군집개수를 설정합니다.
      • 모델생성 : 알고리즘(K-means Clustering, Density-Based Spatial Clustering) 행의 모델 생성 을 클릭하여 모델학습을 수행합니다.
        • 모델생성이 완료되면 모델 분석 버튼이 활성화 됩니다.

    • 모델 분석

      • 모델분석 : '모델 분석' 을 클릭하면 분석정보를 확인할 수 있습니다.
        • 군집 탭에서 행별 군집 결과를 확인하며, 전체다운로드 클릭시 다운로드 됩니다.
      • 그래프 : 군집 결과 산점도를 확인할 수 있습니다.
      • 다운로드 : 모델을 다운로드 할 수 있으며 python 소스코드를 확인합니다.
        • 모델 다운로드 버튼을 클릭하여 모델을 다운로드합니다.

    3.5.4 시계열모델¶

    • 시계열 모델은 시간의 흐름(순서)에 따라 기록된 데이터를 분석하여, 미래의 특정 시점에 일어날 변화를 예측하는 모델입니다.

      • 어제, 오늘 날씨 변화 흐름을 보고 "내일은 비가 올까?"를 예측하는 일기예보와 같습니다.
      • 실제 적용 사례 : 주가 분석, 계절별 전력 수요 예측, 웹사이트 일일 트래픽 전망

    • 모델 학습

      • 예측항목 선정 : 샘플데이터 열기 를 클릭한 후 예측할 숫자 항목을 선택합니다.
      • 날짜변수 선정 : 시간 순서의 기준이 되는 날짜 항목을 선택합니다.
      • 영향요인 선정 : 필요한 경우 예측에 영향을 줄 수 있는 항목을 함께 선택합니다.
      • 예측 기간 : 앞으로 예측할 기간(시점 수)을 입력합니다.
      • 같은 날짜 묶기 : 같은 날짜에 여러 행이 있으면 합계 또는 평균으로 묶어서 학습합니다.
        • 학습 데이터 비율 설정에서 날짜 수와 학습·검증 기간을 확인합니다.
      • 모델학습 : 모델 학습 을 클릭한 후 확인 창에서 예 를 클릭하여 모델학습을 수행합니다.
        • 학습이 끝나면 알고리즘별 MAE, RMSE, MAPE, SMAPE, R2 가 표시됩니다.
      • 모델 저장 후 튜닝, 예측은 회귀 모델과 같은 방법으로 사용합니다.

    3.5.5 이상탐지모델¶

    • 이상탐지 모델은 평범한 데이터 패턴에서 벗어난, 아주 드물게 발생하는 '특이하고 이상한 데이터'를 찾아내는 모델입니다.

      • 수많은 거래 내역 중에서 평소와 다른 "수상한 거래"를 골라내는 것과 같습니다.
      • 실제 적용 사례 : 금융 사기 탐지(FDS), 공장 장비의 고장 징후 예측, 네트워크 해킹 탐지

    • 모델 학습

      • 변수 선정 : 샘플데이터 열기 를 클릭한 후 이상 여부를 판단할 항목을 선택합니다.
      • 이상치 비율 : 전체 데이터 중 이상치로 볼 비율(0.01~0.5)을 입력하거나 슬라이더로 설정합니다.
      • 모델생성 : 알고리즘(K-Nearest Neighbors Detector, Isolation Forest) 행의 모델 생성 을 클릭하여 모델학습을 수행합니다.
        • 학습이 끝나면 이상치 개수와 이상치 비율이 표시되고 모델 분석 버튼이 활성화 됩니다.

    • 모델 분석

      • 이상치 결과 : 행별 이상치 여부를 확인하며, 전체 다운로드 를 클릭하여 다운로드 합니다.
      • 그래프 : 이상치 분포 그래프를 확인합니다.
      • 다운로드 : 모델을 다운로드 할 수 있으며 python 소스코드를 확인합니다.

    4.1 AI로 보고서 만들기¶

    • 데이터와 자료를 제공하여 AI가 자동으로 보고서를 작성하는 기능입니다.
      • 보고서 목록에서 AI로 만들기 버튼을 클릭합니다.
      • 아래와 같이 4개의 STEP(주제, 데이터, 위젯, 미리보기 & 저장) 으로 진행됩니다.
      • 스텝별 작성 관련 자료를 보내어 맞춤형 보고서를 블록 형식으로 작성합니다.

    4.1.1 보고서 주제 선정¶

    • 보고서 작성을 위한 주제를 선정하는 기능입니다.
    • 업로드된 데이터와 연관된 주제로 작성해야 합니다.
      • 제목 / 주제 : 보고서의 주제를 입력합니다.
      • 톤 : 보고서 이용목적에 따라 공식 / 캐주얼 중 선택합니다.
      • 분량 : 요약 / 표준 / 상세 중 하나를 선택합니다.
    톤 표현 예시 활용 목적
    공식 “전월 대비 매출이 12% 증가했습니다.” 업무 보고, 경영진 보고, 대외 제출
    캐주얼 “지난달보다 매출이 12% 늘었어요.” 팀 내 공유, 쉽고 친근한 설명

    4.1.2 데이터셋 선택¶

    • 작성할 보고서의 주요 데이터 셋을 지정합니다.
      • 최대 8개의 데이터셋을 선택할 수 있습니다.
      • 너무 많은 데이터셋은 AI 컨텍스트가 길어져 품질이 떨어질 수 있습니다.

    4.1.3 위젯 추천 · 기존 대시보드 위젯¶

    • 작성한 주제와 선택한 데이터를 AI가 분석하여 위젯을 자동 생성합니다.
    • 주제 관련도와 신뢰도를 기준으로 정렬하며, 채택을 통해 본문 보고서에 추가됩니다.
      • 여러 위젯을 채택할 수 있으며, 모두 채택 / 모두 해제 / 추천 다시 받기 를 사용할 수 있습니다.
      • 보정 버튼으로 추천 위젯의 내용을 수정할 수 있습니다.
    • 기존 대시보드 위젯 : 스튜디오에서 만든 대시보드와 위젯을 선택한 후 + 추가 를 클릭하여 함께 넣습니다.
      • 추가할 항목이 없는 경우 건너뛸 수 있습니다.
      • 위젯을 선택하여 다음 을 클릭합니다.

    4.1.4 미리보기 & 저장¶

    • 작성한 주제와 선택한 데이터를 바탕으로 보고서 본문을 작성합니다.
      • 본문 다시 만들기 를 클릭하여 본문을 재생성할 수 있습니다.
      • 최종 보고서 제목을 확인한 후 보고서 저장 을 클릭합니다.
      • 보고서 저장 후 편집 화면이 열리며, AI로 만들어진 보고서에서 수정이 가능합니다.

    💡 참고 : 생성된 AI 기반 보고서

    4.2 템플릿 만들기¶

    • 보고서를 작성하기 위한 양식을 템플릿으로 작성하여 활용할 수 있습니다.

      • 미리보기 를 눌러 출력 화면을 확인하고 편집 을 눌러 편집모드로 변경합니다.
      • 저장 버튼을 눌러 저장합니다.
      • 기본 템플릿 복원 을 클릭하면 제공되는 기본 템플릿을 다시 불러옵니다.
    • 저장 후 템플릿을 활용하여 보고서를 작성 할 수 있습니다.

    💡 참고 : 템플릿 보고서 만들기

    • 작성된 템플릿으로 신규 보고서를 작성합니다.
      • '템플릿에서 만들기' 를 클릭하고 템플릿을 선택합니다.
      • 불러온 템플릿에서 제목과 블록을 수정합니다.
      • 저장 을 눌러 저장합니다.

    • 보험금 지급 자료를 차트·수치·설명 등으로 구성하여 한 화면에서 확인하는 기능입니다.
    • 예시는 데이터마트의 보험금지급현황을 사용합니다. 위젯별 실습 결과는 각각 별도 대시보드로 저장합니다.

    번호 영역 주요 기능
    1 대시보드 생성·저장 제목 입력, 저장, 다른 이름으로 저장, 실행 취소·다시 실행
    2 페이지·캔버스 속성 페이지 추가·정렬·복제·삭제, 배경 페이지, 배경·크기·간격
    3 위젯 추가 데이터 위젯·텍스트·카드·미디어·문서·안내·이동·도형 추가
    4 배치 정렬·스냅·레이어 자동 정렬, 격자·자석 스냅, 겹침 순서 조절
    5 화면 보기·자동 새로고침 배율, 화면 맞춤, 갱신 주기, 미리보기
    6 AI 도우미 대화로 위젯 생성·수정
    7 공유 멤버 공유, 임베드·퍼블릭 링크

    5.1 대시보드 생성¶

    • 새 대시보드를 만들고 제목을 지정하여 저장하는 기능입니다.
    1. 상단 스튜디오 메뉴에서 새 대시보드 를 클릭합니다.
    2. 상단 제목 입력란에 대시보드 이름을 입력합니다.
    3. 저장 을 클릭하고 저장 창의 제목을 확인한 후 저장 버튼을 클릭합니다.
    4. 위젯을 추가하고 수정한 내용도 저장 버튼을 클릭합니다.

    💡 참고 : 다른 이름으로 저장 · 실행 취소 · 다시 실행

    다른 이름으로 저장 으로 현재 대시보드를 새 이름의 사본으로 저장합니다. 실행 취소 는 직전 편집을 되돌리고, 다시 실행 은 취소한 편집을 다시 적용합니다.

    💡 참고 : 대시보드 목록 관리

    스튜디오 목록에서 전체·내 대시보드·공유받음을 선택하여 목록을 확인합니다. 열기 로 편집 화면에 들어가고, 복제 로 사본을 만들거나 삭제 로 불필요한 대시보드를 제거합니다.

    5.2 페이지·캔버스 속성¶

    • 대시보드를 여러 페이지로 나누고 페이지별 화면 구성을 지정하는 기능입니다.
    1. 왼쪽 페이지 추가 를 클릭합니다.
    2. 페이지 이름을 두 번 클릭하여 이름을 바꾸고, 페이지 행의 위·아래 이동으로 순서를 바꿉니다.
    3. 복제 로 같은 구성의 페이지를 만들고, 불필요한 페이지는 삭제 합니다.

    • 캔버스의 빈 곳을 클릭하면 오른쪽에 페이지 설정이 표시됩니다.
    1. 배경색이나 배경 이미지를 지정합니다.
    2. 캔버스 크기에서 너비(W)와 높이(H)를 입력합니다. 기본값은 1440 × 810입니다.
    3. 위젯 간격을 입력합니다. 자동 정렬 시 적용되며 기본값은 16px입니다.
    4. 설정한 화면을 확인하고 저장 버튼을 클릭합니다.

    💡 참고 : 배경 페이지

    왼쪽 배경 페이지 추가 로 공통 제목이나 안내를 구성합니다. 일반 페이지의 페이지 설정 → 배경 페이지에서 해당 배경을 선택하면 여러 페이지에 공통 구성을 사용할 수 있습니다.

    5.3 위젯 추가¶

    • 차트·수치·문서·설명 등 필요한 요소를 위젯으로 추가하는 기능입니다.
    1. 위젯 추가 를 클릭하고 분류에서 원하는 위젯을 선택합니다. 검색창으로도 찾을 수 있습니다.
    2. 위젯을 선택한 후 오른쪽 속성 패널에서 설정합니다.
    3. 데이터 탭은 데이터셋·컬럼·집계를, 스타일 탭은 제목과 표시 방식을, 배치 탭은 크기와 위치를 지정합니다. 위젯 종류에 따라 표시되는 탭과 항목은 다릅니다.
    4. 캔버스에서 위젯을 드래그하여 이동하고 모서리를 끌어 크기를 조절한 후 저장 버튼을 클릭합니다.

    5.3.1 데이터 위젯¶

    5.3.1.1 차트¶
    • 데이터셋에서 선택한 컬럼의 값을 차트로 시각화하고 비교하는 위젯입니다.
    1. 위젯 추가 → 데이터 위젯 → 차트를 선택합니다.
    2. 차트에 사용할 데이터셋을 선택합니다.
    3. X축에 데이터를 분류할 컬럼을 지정하고, 값에 집계할 컬럼을 추가하여 합계·평균 등 집계 방식을 선택합니다.
    4. 스타일 탭에서 차트 유형과 제목을 설정하고 저장 버튼을 클릭합니다.

    5.3.1.2 KPI¶
    • 선택한 컬럼의 집계 결과를 하나의 핵심 수치로 표시하는 위젯입니다.
    1. 위젯 추가 → 데이터 위젯 → KPI를 선택합니다.
    2. 사용할 데이터셋을 선택하고 값(Y)에 집계할 컬럼과 집계 방식을 지정합니다.
    3. 스타일 탭에서 표시할 수치의 의미에 맞는 제목과 레이블을 입력합니다.
    4. 글자 크기를 조절한 후 저장 버튼을 클릭합니다.

    5.3.1.3 게이지¶
    • 집계값을 지정한 범위 안에서 게이지로 표시하는 위젯입니다.
    1. 위젯 추가 → 데이터 위젯 → 게이지를 선택합니다.
    2. 사용할 데이터셋과 값으로 표시할 컬럼을 선택하고 집계 방식을 지정합니다.
    3. 스타일 탭에서 표시할 값의 의미에 맞는 제목을 입력합니다.
    4. 데이터에 맞게 최소값과 최대값을 설정하고 저장 버튼을 클릭합니다.

    💡 참고 : 게이지 설정 기준

    최소값과 최대값은 게이지에 표시할 데이터의 범위를 정합니다. 비율을 표시하려면 값 형태에서 비율을 선택하고 분자·분모를 지정합니다.

    5.3.1.4 테이블¶
    • 선택한 컬럼의 데이터를 표로 조회하는 위젯입니다.
    1. 위젯 추가 → 데이터 위젯 → 테이블을 선택합니다.
    2. 사용할 데이터셋을 선택하고 표에 표시할 컬럼을 지정합니다.
    3. 정렬 기준이 될 컬럼을 선택하고 오름차순 또는 내림차순으로 정렬 방향을 지정합니다.
    4. 표시할 행 수 제한과 제목을 설정한 후 저장 버튼을 클릭합니다.

    5.3.1.5 피벗¶
    • 행과 열로 데이터를 나누고 집계값을 교차표로 비교하는 위젯입니다.
    1. 위젯 추가 → 데이터 위젯 → 피벗을 선택합니다.
    2. 사용할 데이터셋을 선택하고 행과 열에 데이터를 분류할 컬럼을 지정합니다.
    3. 값 추가 를 클릭하여 집계할 컬럼과 집계 방식을 지정합니다.
    4. 표에 표시된 집계 결과를 확인하고 저장 버튼을 클릭합니다.

    5.3.1.6 필터¶
    • 선택한 조건을 연결된 위젯에 적용하여 데이터를 좁혀 보는 위젯입니다.
    1. 필터를 적용할 데이터 위젯을 같은 페이지에 추가합니다.
    2. 위젯 추가 → 데이터 위젯 → 필터를 선택합니다.
    3. 필터에 사용할 데이터셋과 조건을 선택할 컬럼을 지정합니다.
    4. 적용 대상에서 연결할 위젯을 선택하고 필터 조건에 대응하는 적용 컬럼을 지정합니다.
    5. 미리보기에서 필터 값을 선택하여 연결된 위젯에 조건이 적용되는지 확인한 후 저장 버튼을 클릭합니다.

    5.3.2 텍스트¶

    5.3.2.1 텍스트¶
    • 대시보드의 제목과 설명을 마크다운으로 작성하는 위젯입니다.
    1. 위젯 추가 → 텍스트 → 텍스트를 선택합니다.
    2. 내용(마크다운)에 제목과 설명을 입력합니다.
    3. 글자 크기와 정렬 등 서식을 지정하고 저장 버튼을 클릭합니다.

    5.3.2.2 접이식 설명¶
    • 질문이나 안내 제목을 클릭하여 세부 내용을 펼쳐 보는 위젯입니다.
    1. 위젯 추가 → 텍스트 → 접이식 설명을 선택합니다.
    2. 질문·제목과 내용을 입력합니다. 항목 추가로 설명을 더 넣을 수 있습니다.
    3. 미리보기에서 제목을 클릭하여 내용이 펼쳐지는지 확인합니다.
    4. 편집 화면으로 돌아와 저장 버튼을 클릭합니다.

    5.3.2.3 데이터 기준·출처¶
    • 자료의 집계 기준과 출처를 함께 표시하는 위젯입니다.
    1. 위젯 추가 → 텍스트 → 데이터 기준·출처를 선택합니다.
    2. 자료의 집계 기준이 되는 기간을 입력합니다.
    3. 자료의 출처와 담당자 또는 담당 부서를 입력합니다.
    4. 출처 주소를 입력하고 저장 버튼을 클릭합니다.

    5.3.3 카드¶

    5.3.3.1 정보 카드¶
    • 제목·설명·아이콘과 이동 링크를 한곳에 표시하는 위젯입니다.
    1. 위젯 추가 → 카드 → 정보 카드를 선택합니다.
    2. 제목과 설명을 입력합니다.
    3. 이동할 페이지나 외부 주소를 입력하고 링크 문구를 지정합니다.
    4. 카드 내용을 확인하고 저장 버튼을 클릭합니다.

    5.3.3.2 동적 요약¶
    • 데이터의 집계값을 문장 안에 표시하는 위젯입니다.
    1. 위젯 추가 → 카드 → 동적 요약을 선택합니다.
    2. 사용할 데이터셋과 집계할 컬럼을 선택하고 집계 방식을 지정합니다.
    3. 요약 문장에 {{value}}를 넣어 집계값이 표시될 위치를 지정하고, 필요한 설명과 단위를 함께 입력합니다.
    4. 소수 자릿수를 지정하고 집계값이 포함된 문장을 확인한 후 저장 버튼을 클릭합니다.

    5.3.4 미디어¶

    5.3.4.1 이미지¶
    • 차트 이미지나 안내 그림을 대시보드에 표시하는 위젯입니다.
    1. 대시보드 제목을 입력하고 먼저 저장 버튼을 클릭합니다.
    2. 위젯 추가 → 미디어 → 이미지를 선택합니다.
    3. 이미지 업로드로 파일을 등록하거나 이미지 URL을 입력합니다.
    4. 맞춤 방식을 지정하고 저장 버튼을 클릭합니다.

    5.3.4.2 이미지 갤러리¶
    • 여러 이미지를 격자나 슬라이드로 표시하는 위젯입니다.
    1. 위젯 추가 → 미디어 → 이미지 갤러리를 선택합니다.
    2. 이미지 주소와 사진 설명을 입력하고 항목 추가로 이미지를 더 넣습니다.
    3. 배치를 격자 또는 슬라이드로 선택합니다. 슬라이드를 사용할 경우 자동 넘김 간격을 지정합니다.
    4. 미리보기에서 이미지 전환을 확인하고 저장 버튼을 클릭합니다.

    5.3.4.3 동영상¶
    • 영상 주소를 연결하여 대시보드에서 재생하는 위젯입니다.
    1. 위젯 추가 → 미디어 → 동영상을 선택합니다.
    2. 영상 주소에 MP4·WebM 또는 YouTube 주소를 입력합니다.
    3. 설명을 입력하고 미리보기에서 표시 상태를 확인한 후 저장 버튼을 클릭합니다.

    5.3.5 문서¶

    5.3.5.1 보고서¶
    • 사이트에 저장된 보고서를 대시보드에 표시하는 위젯입니다.
    1. 위젯 추가 → 문서 → 보고서를 선택합니다.
    2. 보고서 목록에서 대시보드에 표시할 보고서를 선택합니다.
    3. 위젯 크기를 조절하여 보고서 내용을 확인하고 저장 버튼을 클릭합니다.

    5.3.5.2 문서·첨부파일¶
    • 문서의 미리보기와 첨부파일 링크를 제공하는 위젯입니다.
    1. 위젯 추가 → 문서 → 문서·첨부파일을 선택합니다.
    2. 미리보기 PDF 주소를 입력합니다.
    3. 파일 이름과 파일 주소를 지정합니다. 필요한 경우 항목 추가로 파일을 더 넣습니다.
    4. 파일 크기 표시 등 옵션을 설정하고 저장 버튼을 클릭합니다.

    • 예제 파일: 문서·첨부파일 위젯 실습용 PDF

    5.3.6 안내·이동¶

    5.3.6.1 링크¶
    • 버튼을 클릭하여 다른 페이지나 외부 주소로 이동하는 위젯입니다.
    1. 위젯 추가 → 안내·이동 → 링크를 선택합니다.
    2. 라벨을 입력하고 대상을 내부 페이지 또는 외부 URL로 지정합니다.
    3. 이동할 페이지나 URL을 설정합니다.
    4. 미리보기에서 이동 동작을 확인한 후 저장 버튼을 클릭합니다.

    5.3.6.2 메뉴¶
    • 대시보드의 여러 페이지로 이동하는 메뉴를 만드는 위젯입니다.
    1. 메뉴에서 이동할 페이지를 먼저 추가합니다.
    2. 위젯 추가 → 안내·이동 → 메뉴를 선택합니다.
    3. 항목별 라벨과 이동할 페이지를 지정합니다.
    4. 방향과 간격을 설정하고 미리보기에서 페이지 이동을 확인한 후 저장 버튼을 클릭합니다.

    5.3.6.3 타임라인·단계 안내¶
    • 업무의 순서나 진행 단계를 시간 흐름에 맞춰 표시하는 위젯입니다.
    1. 위젯 추가 → 안내·이동 → 타임라인·단계 안내를 선택합니다.
    2. 각 항목의 날짜·단계, 제목, 설명을 입력합니다.
    3. 필요한 항목을 추가하고 방향을 세로 또는 가로로 지정합니다.
    4. 단계별 안내 내용을 확인하고 저장 버튼을 클릭합니다.

    5.3.7 도형¶

    5.3.7.1 도형¶
    • 강조 영역이나 배경을 만드는 도형 위젯입니다.
    1. 위젯 추가 → 도형 → 도형을 선택합니다.
    2. 사각형·원·다각형 등 도형 종류를 선택합니다.
    3. 채우기와 테두리, 투명도 등을 지정합니다.
    4. 크기와 위치를 조절하고 저장 버튼을 클릭합니다.

    5.3.7.2 직선¶
    • 영역을 구분하거나 내용을 연결하는 선 위젯입니다.
    1. 위젯 추가 → 도형 → 직선을 선택합니다.
    2. 방향과 회전 각도를 지정합니다.
    3. 두께·색상·선 스타일을 설정합니다.
    4. 길이와 위치를 조절하고 저장 버튼을 클릭합니다.

    5.3.7.3 화살표¶
    • 항목 간 흐름과 연결 방향을 나타내는 위젯입니다.
    1. 위젯 추가 → 도형 → 화살표를 선택합니다.
    2. 경로와 시작·끝 화살촉을 지정합니다.
    3. 두께와 선 스타일을 설정합니다.
    4. 캔버스에서 연결 위치를 조절하고 저장 버튼을 클릭합니다.

    5.3.7.4 설명선¶
    • 말풍선 안에 설명을 넣어 특정 내용을 강조하는 위젯입니다.
    1. 위젯 추가 → 도형 → 설명선을 선택합니다.
    2. 내용(마크다운)에 설명을 입력합니다.
    3. 말풍선의 채우기·테두리·글자 스타일을 지정합니다.
    4. 캔버스에서 꼬리의 꼭짓점을 끌어 설명할 위치에 맞추고 저장 버튼을 클릭합니다.

    5.3.8 저장된 위젯 가져오기¶

    • 차트 시각화·BI(OLAP)·연관관계분석에서 저장한 위젯을 대시보드에 추가하는 기능입니다.
    1. 위젯 추가 → 저장된 위젯 가져오기 를 클릭합니다.
    2. 사용할 위젯을 선택하여 현재 페이지에 추가합니다.
    3. 위젯의 위치와 크기를 조절하고 저장 버튼을 클릭합니다.

    💡 참고 : 가져올 수 있는 위젯

    차트 시각화의 차트, BI(OLAP)의 피벗, 연관관계분석의 저장 화면을 가져올 수 있습니다. 차트의 필터 조건과 정렬은 가져오지 않으므로 추가한 뒤 확인합니다.

    💡 참고 : 저장된 위젯 관리

    스튜디오 목록의 저장된 위젯 탭에서 원본 데이터, 타입, 이름, 사용처와 저장일을 확인합니다. 위젯 이름을 클릭하여 미리보기·속성을 확인하고 수정하거나 스튜디오로 가져오기 를 선택합니다.

    5.4 배치 정렬·스냅·레이어¶

    • 여러 위젯의 배치와 겹침 순서를 조절하는 기능입니다.
    1. 캔버스에서 위젯을 선택하여 원하는 위치로 드래그합니다.
    2. 자동 정렬 을 클릭하면 페이지에 설정한 간격으로 위젯을 격자 배치합니다.
    3. 그리드 스냅 을 켜면 격자에 맞춰 이동하고, 자석 스냅 을 켜면 다른 위젯의 경계와 중심을 기준으로 정렬합니다.
    4. 겹치는 위젯은 앞으로 · 뒤로 도구나 왼쪽 레이어의 순서를 조절하여 표시 순서를 바꿉니다.
    5. 배치 결과를 확인하고 저장 버튼을 클릭합니다.

    💡 참고 : 드래그 중 스냅 해제

    위젯을 드래그하는 동안 Alt 또는 Cmd 키를 누르면 스냅을 일시적으로 해제할 수 있습니다.

    5.5 화면 보기·자동 새로고침¶

    • 화면의 표시 배율과 데이터 갱신 주기를 지정하고 완성된 대시보드를 확인하는 기능입니다.
    1. 상단 배율 목록에서 25%~200% 중 원하는 배율을 선택합니다.
    2. 화면 맞춤 으로 캔버스를 현재 화면에 맞춰 표시합니다.
    3. 자동 새로고침 에서 15초·30초·1분·5분 등 갱신 주기를 선택합니다. 예시는 30초를 사용합니다.
    4. 미리보기 를 클릭하면 편집 패널 없이 대시보드를 확인할 수 있습니다.
    5. 편집 을 클릭하여 편집 화면으로 돌아옵니다.

    5.6 AI 도우미¶

    • 원하는 분석 지표와 화면 구성을 대화로 설명하여 위젯을 생성하거나 수정하는 기능입니다.
    1. 편집 화면의 AI 도우미 를 클릭합니다.
    2. 사용할 데이터셋과 현재 페이지를 확인합니다.
    3. 만들거나 수정할 내용을 입력하고 전송합니다.
    4. 생성된 위젯의 데이터 항목·집계와 배치를 확인합니다.
    5. 공간 부족 안내가 표시되면 배치 탭에서 기존 위젯의 위치·크기를 조절하고, 빈 영역에 필요한 위젯만 추가해 달라고 요청합니다.
    6. 완성된 대시보드를 미리보기로 확인하고 저장 버튼을 클릭합니다.

    💡 참고 : 보험금 지급 현황 요청 예시

    “보험금지급현황 데이터로 보험금 총액·평균 보험금·지급 건수 KPI를 상단에 배치해 주세요. 기존 보험종류별 보험금 합계 차트는 아래쪽 왼편으로 옮기고, 오른편에는 보험사기여부별 건수를 파이 차트로 추가해 주세요. 캔버스 안에서 겹치지 않게 배치해 주세요.”

    💡 참고 : 목록에서 AI 대시보드 생성

    스튜디오 목록의 AI 대시보드 생성 에서 데이터셋을 선택합니다. 바로 생성 은 데이터 통계를 바탕으로 위젯을 자동 배치하고, 대화로 만들기 는 요청을 입력해 구성한 결과를 확인한 뒤 대시보드 만들기 로 저장합니다.

    5.7 공유¶

    • 대시보드의 조회·편집 권한을 다른 멤버에게 부여하거나 임베드·퍼블릭 링크를 만드는 기능입니다.

    5.7.1 멤버 공유¶

    1. 편집 화면 오른쪽 위 공유 → 멤버 공유를 선택합니다.
    2. 검색창에 사용자 이메일이나 그룹명을 입력하고 검색 결과에서 대상을 추가합니다.
    3. 대상별로 조회 또는 편집 권한을 지정합니다. 예시는 지정된 사용자에게 조회 권한을 부여합니다.
    4. 공유된 멤버와 권한을 확인합니다. 변경 내용은 바로 저장됩니다.

    💡 참고 : 원본 데이터셋 조회 권한

    대시보드 공유와 원본 데이터셋의 권한은 별도로 확인합니다. 데이터셋 권한 부족 안내가 표시되면 데이터마트의 해당 데이터셋 공유 설정에서 같은 멤버에게 조회 권한을 부여합니다. 예시는 지정한 멤버에게만 권한을 추가하며 일반 액세스는 제한 상태로 유지합니다.

    5.7.2 임베드·퍼블릭¶

    1. 공유 → 임베드 · 퍼블릭 탭을 선택합니다.
    2. 임베드를 사용할 경우 허용 도메인을 입력하고 임베드 링크·코드를 생성합니다.
    3. 로그인 없이 열 수 있는 대시보드가 필요하면 퍼블릭 링크를 요청합니다.
    4. 관리자가 승인하면 활성화된 퍼블릭 링크를 확인합니다.
    5. 링크를 새 탭에서 열어 대시보드가 표시되는지 확인합니다.

      • 업로드한 데이터 변화 추이 및 전체 트렌드 분석이 가능합니다.
      • 최근 대화 이력을 아카이빙하여 관리합니다.
      • 업로드한 자료에 대한 초기 분석 방향을 제공합니다.
      • 첫 화면에서 최근 대화, 최근 데이터를 눌러 바로 이어서 질문할 수 있습니다.

    6.1 GPT에게 질의하기¶

    💡 참고 : 문서에 대한 질문

    • 문서를 업로드 하여 GPT에게 질문합니다.
      • 새 대화 버튼을 클릭한 후 내문서 버튼을 클릭합니다.
      • 업로드 버튼을 클릭하여 GPT에게 질의할 문서(PDF, HWP, HWPX, DOCX, PPTX)를 업로드 합니다.
      • 문서 행의 AI 버튼을 클릭하여 대화에 추가합니다.
      • GPT에게 해당 문서에 대한 질문정보를 입력한 후 전송 버튼을 클릭합니다.
      • 사용자가 질의한 내용에 대해 문서의 근거 번호와 함께 분석한 결과를 산출합니다.

    💡 참고 : 분석데이터에 대한 질문

    • 분석데이터를 통하여 GPT에게 질문 합니다.
      • 새 대화 버튼을 클릭한 후 내문서 버튼을 클릭합니다.
      • 분석 데이터 목록에서 질문할 데이터 행의 AI 버튼을 클릭하여 대화에 추가합니다.
      • GPT에게 해당 데이터에 대한 질문정보를 입력한 후 전송 버튼을 클릭합니다.
      • 사용자가 질의한 내용에 대해 분석한 결과를 표와 함께 산출합니다.
